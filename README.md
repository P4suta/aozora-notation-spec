# Notation specification

Unofficial Aozora Bunko notation specification and conformance tests.

## Installation

```sh
git clone https://github.com/P4suta/aozora-notation-spec.git
cd aozora-notation-spec
mise install
```

## Usage

```sh
mise x -- just build
```
